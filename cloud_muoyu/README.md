# cloud_muoyu · 摸鱼神器

**极致轻量、伪装更强、纯免费开源**的桌面摸鱼工具。

对标 [wubian123.com](https://wubian123.com/)（Electron 级 ~100MB），本项目基于 **Tauri 2 + Vue 3**，目标包体 **≤ 10MB**、内存 **≤ 120MB**。

## 差异化能力（v1 目标）

- 🎭 **伪装皮肤**：VSCode / Excel / PPT，一键切换"看起来在工作"
- 🕵️ **工作监测自动隐藏**：检测钉钉 / 腾讯会议 / Zoom 等进程启动，秒切伪装
- 🪟 **画中画 + 手势快捷键**：小窗浮动置顶，鼠标手势零学习成本
- 🚨 **全局老板键 + 鼠标移出自动隐藏**（追平 wubian）
- 📑 **多标签浏览 + 内置站点预设**（微信读书 / B站 / 番茄小说 …）

## 技术栈

| 项 | 选择 |
|---|---|
| 桌面框架 | Tauri 2.x |
| 前端 | Vue 3 + Vite + TypeScript |
| 状态 | Pinia |
| 打包目标 | Windows / macOS（Linux 后置） |

## 开发

```bash
# 首次
pnpm install

# 本地开发
pnpm tauri dev

# 打包
pnpm tauri build
```
