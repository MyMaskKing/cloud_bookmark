常见问题

开始之前，你可能想知道

一定要有自己的 WebDAV 吗？
是的，这正是隐私自主的核心。任意支持 WebDAV 的网盘都可以——坚果云、Nextcloud、iCloud、群晖 NAS 等。地址、账号和路径都由你在设置里填写。
换设备后发现书签「丢了」怎么办？
先确认当前是否处于正确的场景，再检查 WebDAV 路径下是否存在对应文件 {场景ID}_bookmarks.json。建议定期在设置里导出 JSON 做本地备份。
多台设备同时修改会冲突吗？
同步采用「最后修改优先」策略。建议先在一台设备改完并等同步完成，再换另一台操作；或用场景把不同用途的书签隔离开。
移动端能用吗？
各移动浏览器对扩展的支持差异较大，建议在桌面浏览器完成配置与日常管理；移动端可使用弹窗与完整管理界面查看、编辑书签。
怎么从浏览器原生书签迁移过来？
在「设置 → 导入导出」里可以从浏览器书签栏导入，也支持 HTML / JSON 文件。还可开启「浏览器书签定时同步场景」，按间隔把原生书签自动写入你指定的云端场景。
